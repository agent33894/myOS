Open any folder: a vault, a repository’s `docs/`, a directory of meeting notes. The file list shows its folders and `.md` files exactly as they are, empty folders included. Dot folders such as `.git` and `.obsidian` are left out, and so is `node_modules`.

A single click opens a note in a preview tab, set in italics, which the next click replaces. Double-click the note, or start typing in it, and the tab stays. Drag a row onto a folder to move it. Each file’s menu can make a note or folder beside it, open it to the side, rename, delete, or copy its path.

Changes made anywhere else, in a terminal, in another editor, or by `git pull`, show up in the list as the watcher sees them. In a Git repository, a small dot marks each changed file. Deleting keeps a local copy first and uses the system trash when there is one.
