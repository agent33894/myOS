The Tasks screen begins with the query `open`: every open task in every note. Type in the query bar to narrow it. `open path:notes/ group:file` shows the tasks in `notes/`, grouped under each note’s title. The buttons below the bar group by file, folder, tag, or date and sort by due date, priority, or file, and they write the same terms into the query.

Each result is a task row. Check it off, set its due or scheduled date from its menu, add a tag, or open the note at that line. The keys follow the list: `j` and `k` move, `x` checks, Enter opens the note with the line lit up for a moment, and ⌘Enter opens it to the side.

When a query is worth keeping, **Save as view** asks for a name and pins it to the sidebar. It is stored in the app’s settings, so no file in your folder changes.
