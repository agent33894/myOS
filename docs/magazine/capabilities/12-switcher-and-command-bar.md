name: Switcher & command bar
headline: Two boxes for everything
dek: ⌘P opens a file. ⌘K runs a command. Both take a few letters and Enter.
how: ⌘P to open a file. ⌘K for commands. `?` for every shortcut.
caption: In the dark theme: the switcher filtered by “ret”, and the command bar filtered by “show”, grouped under Note, Tasks, and Git.
---

The file switcher, ⌘P, searches paths and titles with fuzzy matching, recent files first. Enter opens the file; ⌘Enter opens it in a split to the side. When no file matches the path you typed, the last row offers to create it.

The command bar, ⌘K, lists every command in the app, grouped into Recent, Go to, Note, Tasks, Git, and App, each with its key where it has one. This is where to look when you forget a shortcut. It also searches the text of your notes, so it doubles as a quick find across the folder.

Neither box is a mode. Escape closes them, and nothing has changed. Press `?` anywhere outside the text to see a sheet of every key.
