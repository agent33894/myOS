Backlinks sit in the right panel, in two parts. **Linked from** lists every note with a link to this one, by `[[wikilink]]` or ordinary Markdown link, with the line that holds it. Click an entry to go there.

**Unlinked mentions** lists notes that use this note’s title in plain text, with no link. Each one has a **Link** button, which turns that mention into a `[[link]]`. The change is one edit to one line in the other file, and it can be undone like any other.

The panel reads the whole folder, so it finds links in daily notes, meeting notes, and old files you have not opened in months. Nothing is stored in the folder to make this work: backlinks are worked out from the text of the notes themselves.
