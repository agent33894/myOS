A red number that grows every morning is a small daily reprimand. The behavioral research traces why it backfires: shame lowers people's sense of autonomy and competence, which self-determination theory ties to lasting motivation. The guardrails put it bluntly: no red aging counts and no guilt copy.

So "Overdue" is now **Carried over**, set in the same neutral secondary colour as other quiet information. Beside it sits **Re-plan**, which opens a short batch dialog: "Pick a new day for each task, or move them all at once. It's fine to leave something where it is." Each row notes when it was due, and each can go to Today, Tomorrow, Next week, Someday, or No date, one by one or all together.

When every task has somewhere to go, the dialog says so: "Everything has a new day." Dated checklist items keep their dates in their notes, and the dialog tells you so rather than rewriting them. Leaving everything alone is always allowed.
