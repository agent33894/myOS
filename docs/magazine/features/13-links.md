The student in the persona walkthroughs found the links half-finished. Typing `[[` offered no suggestions, and a link to a page that did not exist looked exactly like one that did.

In 3.0, `[[` opens a small menu of pages as you type. Matches rank from exact, to prefix, to word start, down to loose letters in order, so "wkrv" can still find "Weekly review", and ties go to what you opened last. When nothing fits, the last row reads Create "…".

A link to a page that does not exist yet is drawn dashed and muted, with the hint Create "…" on hover. Click it, and the note is created and opened.

At the foot of every page, **Linked from** lists the pages that point here. **Unlinked mentions** lists other notes that use this page's title as plain text. Beside each sits a single **Link** button. It rewrites only that occurrence, checks the file's revision first, and can be undone in one step. If the text has moved on in the meantime, the app writes nothing and tells you: "That mention has changed. Nothing was linked."
