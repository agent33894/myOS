# Security Policy

## Supported versions

Security fixes are applied to the latest published myOS release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing exploit details, private Markdown content, credentials, or local filesystem paths.

myOS is a desktop application that is allowed to read and write the workspace folder selected by the user. Reports involving path traversal, unsafe link or protocol handling, renderer-to-main privilege escalation, dependency compromise, or unintended network access are especially useful.
